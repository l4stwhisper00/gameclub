# Настольный клуб 🎲

Адаптивный сайт-клуб для настольных и ролевых игр. Работает как статический проект на HTML, CSS и нативных JavaScript ES-модулях — без npm, сборки и фреймворков.

## Возможности

- Регистрация и вход по email и паролю.
- Профиль игрока, публичная страница, любимые игры и редактор аватара.
- Каталог игр с поиском, категориями и карточками подробностей.
- Создание публичных и приватных комнат, приглашения, настройки правил и роли ведущего/игрока.
- Чат комнаты с историей, системными событиями и индикатором присутствия.
- Адаптивный тёмный интерфейс с анимациями и поддержкой `prefers-reduced-motion`.

## Локальный запуск

ES-модули и Web Crypto нужно запускать через HTTP(S), а не напрямую через `file://`.

Например, из корня проекта:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Публикация на GitHub Pages

1. Загрузи содержимое архива в корень репозитория, сохранив папки `css/` и `js/`.
2. Открой **Settings → Pages**.
3. Выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохрани настройки и открой адрес опубликованного сайта.

## Важные ограничения текущей версии

Это клиентский демонстрационный проект без серверной части. Аккаунты, комнаты и сообщения хранятся в `localStorage` конкретного браузера: данные не синхронизируются между разными устройствами и браузерами и могут быть очищены настройками браузера. Чат и присутствие синхронизируются между вкладками одного браузера.

Хэширование паролей на клиенте не заменяет серверную авторизацию. Не используй эту версию для хранения настоящих учётных данных или конфиденциальной информации. Для публичного многопользовательского сервиса потребуется backend, серверная проверка доступа и постоянная база данных.
